# Flame Ring V2 P4.3 — 火焰边缘定型

## 参考目标

依据当前 16 帧参考图：

- 01–04：火环成形，外缘开始出现方向明确的火舌，而不是光滑的椭圆线。
- 05–09：满环燃烧期间，火焰轮廓保持高频起伏，但内圈必须清楚、核心不能被噪声淹没。
- 10–12：进入破碎前，外缘持续卷动，轮廓变化不能呈现逐帧随机闪烁。
- 13–16：剩余火焰逐渐变稀，明暗边缘仍受真实火焰 alpha 限制，不得在透明区域制造染色。

## 本阶段修改

### 1. 几何边缘使用两端独立的多频轮廓

文件：`FlameRingRenderer.java`

每个 segment 的两端分别采样 `flameEdgeProfile`，使用低频起伏、中频弯曲和高频尖锐变化组成稳定的轮廓函数。它以片段索引、实体 ID 和连续时间为参数，不在每帧重新抽随机数，因此波动连续且不会随机跳变。

Outer、Body、Core 使用分级边缘粗糙度：

- Outer：较强的外缘尖峰与不规则火舌轮廓；
- Body：保留中等幅度起伏，承接外焰；
- Core：只保留很弱的扰动，尽量维持窄、亮、连续。

内缘的扰动幅度明显低于外缘，确保火环中空部分依然容易辨认。各层仍共用原有弧段参数、Reveal Curve 和环段位置。

### 2. 火舌从近似均匀分布改为稳定空间簇

外缘火舌的入选概率由低频空间簇调节。火舌位置的选择仍由实体 ID 与段索引决定；每根火舌的长度会随空间簇参数变化，因此轮廓更接近参考图中密集区域与稀疏区域交替的火焰群，而不是均匀梳齿。

火舌的动态脉动继续沿用现有连续函数，不增加逐帧随机创建/删除模式。

### 3. Shader 将边缘流动与炽核分离

文件：`shaders/post/flame_ring_distort.fsh`

- Outer UV 流动扰动提高到 `strength * 7.4`，承担最明显的边缘翻卷。
- Body 维持中等扰动。
- Core 扰动降低到 `strength * 2.8`，保持火环内部的锋利亮线。
- Edge Burn 增加多频噪声闪烁，但由当前外焰 alpha 门控，因此透明区域不会仅凭噪声凭空发红。
- 保留现有 `tint` 的 alpha 门控，避免破坏此前的透明区域回归修复。

## 保持不变

- `FlameRingCastCurve` 的 5 + 6 + 4 + 5 tick 时间轴。
- P4.1 的确定性裂解槽、碎片运动与粒子续流。
- P4.2 的三材质剑斩环头及环头持续逻辑。
- P0 深度附件修复、P1 FlameRingPass 隔离与 CA0 fallback。
- 施法、网络同步、伤害、消耗、冷却逻辑。
- 不实施 P3 的通用 Pass 或动态颜色附件分配。

## 验收清单

源码检查：

1. Outer、Body、Core 使用分级轮廓粗糙度。
2. 同一 segment 的两端使用不同轮廓采样，产生连续 taper，不再整段等宽。
3. 内缘比外缘更稳定。
4. 火舌空间分布固定，不因每帧重新随机而闪烁。
5. Shader 的 edge burn 受外焰 alpha 门控。
6. 原 20 tick 时间轴和 P4.1 / P4.2 共享逻辑未修改。

游戏内检查：

- 01–04：边缘从细火线逐步变为可读火焰环。
- 05–09：外焰自然翻卷、内缘仍然清晰、核心不会变成厚重光带。
- 10–12：边缘动态与 P4.1 的裂解过渡不冲突。
- 13–16：只剩有效火焰/火星，不出现屏幕级发红或轮廓闪烁。
- 第一人称、斜视角以及公共后处理 fallback 均未出现回归。
