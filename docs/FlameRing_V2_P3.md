# Flame Ring V2 P3 — 3D Volume + Tangent Flow

本阶段继续保持 V2 P2 的三材质 FBO 架构，不修改 FlameRingEntity 的同步字段、Reveal Curve、寿命与 ISS 法术逻辑。

## 核心变化

火环主体从单层平面 Ribbon 升级为“挤出式体积带”：

- 每个 segment 同时生成前表面、后表面、外侧壁、内侧壁。
- 外焰 / 主焰 / 炽核仍分别进入 CA1 / CA2 / CA3。
- 不同材质拥有不同厚度：Outer > Body > Core，保证核心仍然锐利。
- 流场沿环向移动，通过 segment 参数产生低频鼓包 + 高频翻卷；不是重新随机火环形状，因此不会破坏 Reveal Curve。

## 火舌与环头

P1 的离散火舌继续保留，并增加法向深度偏移。

环头同时增加轻微法向厚度脉动，使剑尖位置保持明确，同时不再像一张完全平的三角片。

## 溃散

残片运动由“切向 + 径向”升级为“切向 + 径向 + 法向”，让解体阶段具有空间散射感。原有稳定随机阈值仍保持，避免每帧闪烁。

## Shader Flow

flame_ring_distort.fsh 从单纯 screen-space warp 升级为：

1. 从 Outer alpha 局部梯度估计火环切向；
2. 沿切向做时间驱动的流动采样；
3. 再叠加小尺度 FBM 扭曲；
4. 三层材质保持独立色彩与 Edge Burn / Core Halo。

这样后处理的扰动方向与圆环局部切线一致，而不是简单地把整圈火焰水平/垂直抖动。

## 约束

P3 不改：

- FlameRingEntity 网络同步；
- FlameRingCastCurve 时间轴；
- 法强伤害逻辑（本 VFX 为纯视觉）；
- ISS 法术消耗与 cooldown；
- 后处理失败时的 fallback 路径。

## 验证重点

实际客户端验证时优先观察：

- 斜视角是否能看出火环厚度，而不是一张纸；
- Outer 是否出现沿圆周移动的鼓包；
- Core 是否仍保持尖锐、不会被厚度淹没；
- 溃散残片是否出现明显前后空间分离；
- 屏幕空间流动是否沿环向，而不是整屏横移；
- Bloom 是否仍只作用于最终火环贡献，没有把其他 CA0 特效一起扭曲。

当前阶段仅完成代码与结构更新，尚未宣称 Minecraft 客户端运行验证通过。
